# Консольный менеджер текстовых файлов на Bash

Интерактивный Bash-скрипт для удобного управления содержимым текстовых файлов прямо из терминала. С его помощью можно быстро искать, редактировать и удалять строки или слова, не открывая тяжелые текстовые редакторы.

## 🚀 Возможности

Скрипт предоставляет интерактивное текстовое меню со следующими функциями:

* **Поиск подстроки (Опция 1):**
  * Проверяет наличие слова в файле.
  * Выводит точную позицию подстроки в байтах (`grep -ob`).
  * Показывает номер строки и само совпадение (`grep -no`).
  * Выводит номер строки и её полное содержимое (`grep -n`).
* **Редактирование / Замена (Опция 2):**
  * Замена первого совпадения в каждой строке (`sed "s/.../.../"`).
  * Глобальная замена всех совпадений во всем файле (`sed "s/.../.../g"`).
* **Удаление (Опция 3):**
  * Удаление конкретной строки по её номеру.
  * Удаление диапазона строк (например, `1,5` удалит строки с первой по пятую).
* **Вставка (Опция 4):**
  * *В разработке (заготовка в меню).*

## 🛠 Требования

Для работы скрипта необходима стандартная командная строка Linux/macOS (Bash) и предустановленные утилиты:
* `grep`
* `sed`


## ⚠️ Важное примечание
Функции редактирования и удаления изменяют файлы **напрямую** (`sed -i`). Перед использованием рекомендуется сделать резервную копию важных данных.
